# WiDS Datathon 2025
## Описание проекта
Нервно-психические расстройства, возникающие в процессе развития, такие как тревога, депрессия, аутизм и синдром дефицита внимания с гиперактивностью, или СДВГ, часто различаются по тому, как и в какой степени они влияют на мужчин и женщин. СДВГ встречается примерно у 11% подростков, при этом примерно у 14% мальчиков и 8% девочек этот диагноз установлен. Есть некоторые свидетельства того, что девочки с СДВГ часто остаются недиагностированными, поскольку у них, как правило, больше симптомов, на которые они не обращают внимания и которые труднее обнаружить. Девочки с недиагностированным СДВГ будут продолжать страдать от симптомов, которые негативно сказываются на их психическом здоровье и способности функционировать.
Поставлена задача построить модель, позволяющую предсказать пол человека и его диагноз СДВГ, используя данные функциональной визуализации мозга детей и подростков, а также их социально-демографическую информацию, эмоции и информацию о воспитании.

Контрольный вопрос и задание: “Какие паттерны мозговой активности связаны с СДВГ; отличаются ли они у мужчин и женщин, и если да, то каким образом?”

Задача состоит в том, чтобы создать модель с несколькими исходами для прогнозирования двух отдельных целевых переменных: 1) СДВГ (1= да или 0=нет) и 2) женщины (1=да или 0=нет).
В рамках проекта выполнены следующие этапы:

- Исследовательский анализ данных (EDA).
- Предобработка данных.
- Построение базовых моделей (Baseline).
- Подбор гиперпараметров с помощью Optuna.
- Построение ансамблевой модели Stacking.
- Оптимизация порогов классификации (Threshold Optimization).
- Финальная оценка моделей на тестовой выборке.

## Исследовательский анализ данных (EDA)
- Пол влияет на диагностирование СДВГ, у мальчиков чаще диагностируюется на 12,8%
- Большим влиянием на диагностирование СДВГ у любого пола являются эмоционально/поведенческие признаки: Гиперактивность, экстернализация, общая сложность ребенка, насколько проблемы влияют на жизнь, проблемы в поведении, интернализация, дисциплина

Полученные результаты были использованы для выбора подхода к предобработке данных и дальнейшего построения моделей классификации.

## Предобработка данных
На данном этапе была выполнена подготовка данных для обучения моделей:
Способы обработки пропусков:
- Удалялись строчки, где немного пропущенных значений
- Для признаков PreInt_Demos_Fam_Child_Ethnicity = 3, PreInt_Demos_Fam_Child_Race = 10 соответствует значению unknow
- Для признаков со значением -1, было выбрато значение несущестующее 
- Для признака ColorVision_CV_Score была взята медиана
- Кодирование категориальных признаков методом One-Hot Encoding с использованием pandas.get_dummies().
- Масштабирование признаков с помощью StandardScaler для Logistic Regression.
- Разделение данных на обучающую, валидационную и тестовую выборки с использованием train_test_split и стратификации по целевой переменной.

Итоговое соотношение выборок:

- Train — 67,2%.
- Validation — 12,8%.
- Test — 20%.

Валидационная выборка использовалась для сравнения моделей и подбора порогов классификации. Тестовая выборка не использовалась при обучении, выборе моделей и настройке порогов и применялась только для финальной оценки качества.

## Ансамблевая модель Stacking
На следующем этапе был реализован стекинг моделей отдельно для каждой целевой переменной: ADHD и Sex_F.

Базовые модели:
- Logistic Regression.
- LightGBM.
- CatBoost.

В качестве метамодели использовалась Logistic Regression.

В качестве базовых моделей использовались наиболее эффективные алгоритмы, отобранные по результатам экспериментов с базовыми моделями и Optuna.

При выборе учитывались результаты на валидационной выборке и средние значения ROC-AUC по результатам 5-fold кросс-валидации. Если базовая модель показывала лучшие результаты, чем модель с оптимизированными гиперпараметрами, предпочтение отдавалось базовой модели.

Построение ансамбля включало следующие этапы:

1. Генерация out-of-fold (OOF) предсказаний базовых моделей на обучающей выборке.
2. Формирование метапризнаков на основе полученных предсказаний.
3. Обучение метамодели Logistic Regression на OOF-предсказаниях.
4. Получение предсказаний базовых моделей на валидационной и тестовой выборках.
5. Передача метапризнаков в обученную метамодель для получения итоговых предсказаний.

## Выводы

В ходе проекта были исследованы различные алгоритмы машинного обучения, проведён подбор гиперпараметров с помощью Optuna и реализован стекинг моделей.

По результатам экспериментов для двух целевых переменных были выбраны разные финальные модели:

ADHD - LightGBM

Модель показала достаточно сбалансированные результаты по положительному классу: Precision составил 0.810, Recall - 0.855, F1-score - 0.832. Это говорит о том, что модель не только достаточно точно определяет положительный класс, но и обнаруживает большую часть соответствующих объектов.

Sex_F - Stacking

Модель показала ROC-AUC 0.755, однако при выбранном пороге классификации Precision составил 0.586, а Recall - 0.447. Это указывает на ограниченную способность модели обнаруживать объекты положительного класса: она пропускает более половины таких объектов. Несмотря на это, модель была выбрана как лучшая среди исследованных вариантов по результатам валидации.
